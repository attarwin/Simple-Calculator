# Simple Calculator (Vault App)

A lightweight Android calculator app with a hidden privacy vault and virtual space features.

## Features
- **Disguised UI:** Standard calculator interface named "Simple Calculator".
- **Secret Unlock:** Enter PIN (`1234`) and press `=` to access hidden space.
- **Auto-Hide Privacy:** Automatically disappears from Recent Apps when Home button is pressed (`excludeFromRecents` + `finishAndRemoveTask()`).

## How to Build
1. Clone this repository into Android Studio.
2. Build and run on an Android device or emulator.
